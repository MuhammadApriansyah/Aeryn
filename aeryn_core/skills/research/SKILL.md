# Research Skill

## Description
Systematic information gathering with citations and cross-referencing.

## Trigger Keywords
- riset, research, cari tahu, investigasi, deep dive, cari, search

## Behavior Contract

### 1. Identify Research Questions
- Extract key entities and relationships from the goal
- Determine what information is needed
- Identify potential sources

### 2. Search Strategy
- Use web_search with targeted queries (max 400 char)
- Generate multiple query variations for coverage
- Prioritize authoritative sources

### 3. Source Evaluation
- Cross-reference minimum 2 sources
- Prefer primary sources over secondary
- Note publication dates for timeliness
- Flag potential bias or conflicts of interest

### 4. Synthesis
- Summarize findings in structured format
- Cite sources naturally inline
- Highlight consensus vs. controversy
- Note gaps in available information

### 5. Output Format
```
## Ringkasan
[2-3 sentence overview]

## Detail
[Structured findings with inline citations]

## Sumber
1. [Source 1](url) — key finding
2. [Source 2](url) — key finding

## Catatan
[Limitations or gaps in research]
```

## Constraints
- Never fabricate sources or data
- Always distinguish fact from opinion
- Flag when information is outdated or uncertain
- Maximum 5 sources per research task
